[Strata](https://strata.so/) 是一款开源项目管理工具：跟踪工作项、跑 ~迭代~ 周期（Cycle）、管理产品路线图，同时不必再为管理工具本身消耗精力。🧘‍♀️

> Strata 每天都在演进。你的建议、想法和 bug 反馈对我们非常重要。欢迎到[论坛](https://forum.strata.so)参与讨论，或直接提交 GitHub Issue——我们都会读，并且会回复大部分内容。

## 🚀 安装

上手 Strata 很简单，选一种适合你的方式：

- **Strata 云服务**
  在 [Strata Cloud](https://app.strata.so) 注册免费账号，这是最快的方式，不需要关心任何基础设施。

- **私有化部署**
  如果希望完全掌控数据和基础设施，可以在自己的服务器上安装运行 Strata。请参考[部署指南](https://developers.strata.so/self-hosting/overview)。

| 部署方式   | 文档                                                                                                                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Docker     | [![Docker](https://img.shields.io/badge/docker-%230db7ed.svg?style=for-the-badge&logo=docker&logoColor=white)](https://developers.strata.so/self-hosting/methods/docker-compose)         |
| Kubernetes | [![Kubernetes](https://img.shields.io/badge/kubernetes-%23326ce5.svg?style=for-the-badge&logo=kubernetes&logoColor=white)](https://developers.strata.so/self-hosting/methods/kubernetes) |

实例管理员可以通过 [God mode](https://developers.strata.so/self-hosting/govern/instance-admin) 配置实例级设置。

## 🌟 功能

- **工作项（Work Items）**
  用支持文件上传的富文本编辑器高效创建和管理任务，通过子属性和关联工作项让组织和跟踪更清晰。

- **周期（Cycles）**
  用周期保持团队节奏，借助燃尽图等工具轻松跟踪进展。

- **模块（Modules）**
  把复杂项目拆成更小、更好管理的模块。

- **视图（Views）**
  通过自定义筛选只展示最相关的工作项，并随时保存、分享这些视图。

- **页面（Pages）**
  用 Strata Pages 记录和整理想法，支持 AI 能力与富文本编辑：排版、插图、加超链接，或把笔记直接转成可执行的工作项。

- **分析（Analytics）**
  实时查看 Strata 中的各类数据，识别趋势、清除阻塞，让项目持续向前。

# Strata

<p align="center"><b>Modern project management for all teams</b></p>

Meet [Strata](https://strata.so/), an open-source project management tool to track issues, run ~sprints~ cycles, and manage product roadmaps without the chaos of managing the tool itself. 🧘‍♀️

> Strata is evolving every day. Your suggestions, ideas, and reported bugs help us immensely. Do not hesitate to join in the conversation on [Forum](https://forum.strata.so) or raise a GitHub issue. We read everything and respond to most.

## 🚀 Installation

- **Strata Cloud** — sign up for a free account on [Strata Cloud](https://app.strata.so); it is the fastest way to get running without worrying about infrastructure.
- **Self-host Strata** — install and run Strata on your own servers. Follow the [deployment guides](https://developers.strata.so/self-hosting/overview).

| Installation methods | Docs link                                                                                                                                                                                |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Docker               | [![Docker](https://img.shields.io/badge/docker-%230db7ed.svg?style=for-the-badge&logo=docker&logoColor=white)](https://developers.strata.so/self-hosting/methods/docker-compose)         |
| Kubernetes           | [![Kubernetes](https://img.shields.io/badge/kubernetes-%23326ce5.svg?style=for-the-badge&logo=kubernetes&logoColor=white)](https://developers.strata.so/self-hosting/methods/kubernetes) |

`Instance admins` can configure instance settings with [God mode](https://developers.strata.so/self-hosting/govern/instance-admin).

## 🌟 Features

- **Work Items** — create and manage tasks with a rich text editor that supports file uploads, sub-properties and references to related issues.
- **Cycles** — keep momentum with cycles, and track progress with burn-down charts and other tools.
- **Modules** — break complex projects into smaller, manageable modules.
- **Views** — build filters that show only the relevant issues, then save and share those views.
- **Pages** — capture ideas with Strata Pages, including AI capabilities and a rich text editor; format text, insert images, add links, or turn notes into actionable items.
- **Analytics** — get real-time insight across your Strata data, spot trends, remove blockers and keep projects moving.
